## 实施方案

### 阶段一："更多"跳转（优先）

**目标**：点击聊天面板 "更多 >" 跳转到现有 cron 页面。

**改动文件**：
- `ui/src/ui/views/chat-standalone/empty-state.ts` — 添加跳转逻辑

**实现**：
```typescript
// 在 renderCronTaskPanel 的 header-right 添加点击事件
@click=${() => {
  const basePath = props.basePath?.trim().replace(/\/$/, "") ?? "";
  window.location.href = `${basePath}/cron`;
}}
```

### 阶段二：卡片式布局（核心）

**目标**：在现有 `cron.ts` 基础上新增卡片视图模式，匹配 Figma 设计。

**改动文件**：
1. `ui/src/ui/views/cron.ts` — 新增 `renderCronCardGrid` 函数
2. `ui/src/styles/cron.css`（或 `chat-standalone.css`）— 卡片样式

**新增渲染函数**：

```typescript
function renderCronCardGrid(props: CronProps): TemplateResult {
  return html`
    <div class="cron-card-grid">
      ${props.jobs.map(job => renderCronCard(job, props))}
    </div>
  `;
}

function renderCronCard(job: CronJob, props: CronProps): TemplateResult {
  const isRunning = job.state?.runningAtMs != null;
  const isEnabled = job.enabled;

  return html`
    <div class="cron-card">
      <div class="cron-card__body">
        <div class="cron-card__icon">${icons.brain}</div>
        <div class="cron-card__content">
          <div class="cron-card__title-row">
            <span class="cron-card__title">${job.name}</span>
            <button class="cron-card__play-btn"
              @click=${() => props.onToggle(job, !isEnabled)}>
              ${isEnabled ? icons.pause : icons.play}
              <span>${isEnabled ? '运行中' : '已暂停'}</span>
            </button>
          </div>
          <div class="cron-card__desc">
            ${job.payload.kind === 'systemEvent'
              ? job.payload.text
              : job.payload.message}
          </div>
        </div>
      </div>
      <div class="cron-card__footer">
        <div class="cron-card__schedule">
          <span class="cron-card__alarm-icon">${icons.alarm}</span>
          <span>${formatCronSchedule(job)}</span>
        </div>
        <div class="cron-card__status">
          ${job.state?.lastRunAtMs
            ? `上次执行 ${formatRelativeTimestamp(job.state.lastRunAtMs)}`
            : '--'}
        </div>
      </div>
    </div>
  `;
}
```

### 阶段三：搜索与筛选（增强）

**目标**：添加搜索框和分段控制器，匹配 Figma 顶部工具栏。

**改动文件**：
- `ui/src/ui/views/cron.ts` — 在 `renderCronPage` 中添加搜索栏和筛选器

**实现**：
```typescript
function renderCronToolbar(props: CronProps): TemplateResult {
  return html`
    <div class="cron-toolbar">
      <div class="cron-toolbar__left">
        <!-- 分段控制器：全部/已启用/已禁用 -->
        <div class="cron-segmented">
          <button class="cron-segmented__item ${props.jobsEnabledFilter === 'all' ? 'active' : ''}"
            @click=${() => props.onJobsFiltersChange({ cronJobsEnabledFilter: 'all' })}>
            全部
          </button>
          <button class="cron-segmented__item ${props.jobsEnabledFilter === 'enabled' ? 'active' : ''}"
            @click=${() => props.onJobsFiltersChange({ cronJobsEnabledFilter: 'enabled' })}>
            已启用
          </button>
          <button class="cron-segmented__item ${props.jobsEnabledFilter === 'disabled' ? 'active' : ''}"
            @click=${() => props.onJobsFiltersChange({ cronJobsEnabledFilter: 'disabled' })}>
            已禁用
          </button>
        </div>
      </div>
      <div class="cron-toolbar__right">
        <label class="cron-toolbar__search">
          <span class="cron-toolbar__search-icon">${icons.search}</span>
          <input type="search" placeholder="搜索任务"
            .value=${props.jobsQuery}
            @input=${(e) => props.onJobsFiltersChange({
              cronJobsQuery: (e.target as HTMLInputElement).value
            })} />
        </label>
        <button class="cron-toolbar__add" @click=${() => props.onAdd()}>
          新增
        </button>
      </div>
    </div>
  `;
}
```

## 数据映射

| Figma 元素 | 数据源 | 字段 |
|-----------|--------|------|
| 任务名称 | `CronJob.name` | "新能源汽车周报" |
| 运行状态按钮 | `CronJob.enabled` + `CronJob.state.runningAtMs` | ▶运行中 / ⏸已暂停 |
| 描述信息 | `CronJob.payload.message` / `payload.text` | 任务描述 |
| 调度规则 | `formatCronSchedule(CronJob)` | "每天 09:00" |
| 上次执行时间 | `CronJob.state.lastRunAtMs` | "2分钟前" |
| 思考规划图标 | 任务类型图标 | 根据payload.kind选择 |

## 实施优先级

| 优先级 | 阶段 | 工作量 | 依赖 |
|--------|------|--------|------|
| P0 | 阶段一："更多"跳转 | 0.5h | 无 |
| P1 | 阶段二：卡片布局 | 2h | 阶段一 |
| P2 | 阶段三：搜索筛选 | 1h | 阶段二 |
| P3 | 阶段四：独立路由 | 3h | 阶段二 |

## 建议

1. **优先实现阶段一**，确保"更多"按钮可跳转到现有 cron 页面
2. **阶段二采用渐进方式**：在现有 cron.ts 中新增卡片视图，保留原列表视图作为切换选项
3. **阶段四可选**：如果需要完全匹配 Figma 的独立页面布局（含左侧导航），则需要在 standalone 路由下新增子页面
