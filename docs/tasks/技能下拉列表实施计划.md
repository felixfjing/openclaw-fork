# 技能下拉列表实施计划

> 基于 Figma 设计稿 node 12:43991 中的"技能"按钮交互需求

## 方案概述

在聊天输入框工具栏的"技能"按钮点击后，展示当前工作区下的技能列表下拉菜单。用户选择技能后，自动在输入框中插入 `/skill <skillKey>` 前缀。

## 技术依赖（已存在）

| 组件 | 位置 | 说明 |
|------|------|------|
| `skills.status` RPC | `src/gateway/server-methods/skills.ts` | 返回 `SkillStatusReport` |
| `SkillStatusEntry` 类型 | `src/agents/skills-status.ts` | 含 `name/emoji/description/disabled/eligible` |
| `SkillStatusReport` 类型 | `ui/src/ui/types.ts` | 含 `skills[]` 和 `workspaceDir` |
| Gateway Browser Client | `ui/src/ui/gateway.ts` | 挂载在 `ChatProps` 上 |

## 关键代码示例

### state.ts 新增

```ts
// chatViewState 新增字段
skillsList: [] as Array<{ name: string; skillKey: string; emoji?: string; description: string }>,
skillsListLoaded: false,
skillsDropdownOpen: false,

export async function loadSkillsList(client: { request: Function }) {
  if (chatViewState.skillsListLoaded) return;
  try {
    const res = await client.request("skills.status", {});
    if (res?.skills) {
      chatViewState.skillsList = res.skills
        .filter((s: any) => s.eligible && !s.disabled)
        .map((s: any) => ({
          name: s.name,
          skillKey: s.skillKey,
          emoji: s.emoji,
          description: s.description ?? "",
        }));
      chatViewState.skillsListLoaded = true;
    }
  } catch {}
}
```

### chat-standalone.ts 渲染

```ts
// renderChatStandalone 中加载技能
if (!chatViewState.skillsListLoaded && props.connected) {
  void loadSkillsList(props.client);
}

// 技能按钮修改
<button
  class="agent-chat__toolbar-chip ${chatViewState.skillsDropdownOpen ? 'active' : ''}"
  @click=${() => { chatViewState.skillsDropdownOpen = !chatViewState.skillsDropdownOpen; requestUpdate(); }}
>
  ...
</button>
${chatViewState.skillsDropdownOpen ? renderSkillsDropdown(props, requestUpdate) : nothing}
```

## 影响范围

仅影响 standalone 聊天模式（`.chat--standalone` 选择器内），不影响嵌入式聊天或其他页面。
