# Gildata Provider 结构化日志实现任务

## 任务概述
为warrenq认证和API调用添加结构化日志记录，提高生产环境中的调试能力。

## 实现计划

### 1. 创建日志工具模块
- [ ] 创建 `extensions/gildata/src/logger.ts` - 日志工具模块
- [ ] 创建 `extensions/gildata/src/types.ts` - 日志相关类型定义
- [ ] 实现日志级别配置
- [ ] 实现敏感数据脱敏函数

### 2. 在认证模块添加日志
- [ ] 在 `warrenq-auth.ts` 中添加登录流程日志
- [ ] 记录登录尝试（成功/失败）
- [ ] 记录Token存储操作
- [ ] 添加用户名脱敏

### 3. 在API调用模块添加日志
- [ ] 在 `dynamic-models.ts` 中添加API请求日志
- [ ] 记录请求详情（URL、方法、headers脱敏）
- [ ] 记录响应状态
- [ ] 记录错误信息

### 4. 在主入口添加日志
- [ ] 在 `index.ts` 中添加provider discovery日志
- [ ] 记录模型发现流程
- [ ] 记录运行时认证准备

### 5. 配置选项
- [ ] 添加配置选项以启用/禁用详细日志
- [ ] 实现基于环境变量的日志级别控制
- [ ] 默认生产环境不输出详细日志

### 6. 文档和示例
- [ ] 创建日志实现文档
- [ ] 提供日志输出示例
- [ ] 说明如何启用/禁用日志

## 实施细节

### 日志策略
- 使用JSON格式输出
- 包含时间戳、日志级别、子系统、关联ID
- 脱敏密码、token、API密钥等敏感信息
- 支持debug、info、warn、error四个级别

### 兼容性
- 尽可能与OpenClaw现有日志系统兼容
- 使用结构化日志格式
- 支持文件和控制台输出

- [ ] 验证日志级别过滤
- [ ] 验证关联ID传递
