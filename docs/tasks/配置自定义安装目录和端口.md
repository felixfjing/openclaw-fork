# OpenClaw 自定义安装目录和端口配置方案

> 作者：胡丹
> 创建日期：2026-04-14

## 概述

本文档总结了本地编译安装 OpenClaw 时，如何自定义安装目录、网关端口和 WebSocket 端口的配置方案。

## 配置位置

### 1. 安装/状态目录配置

#### 环境变量

| 环境变量 | 作用 | 默认值 |
|-----------|------|---------|
| `OPENCLAW_STATE_DIR` | 状态目录（sessions、logs、caches） | `~/.openclaw` |
| `OPENCLAW_CONFIG_PATH` | 配置文件路径 | `~/.openclaw/openclaw.json` |
| `OPENCLAW_HOME` | 主目录（用于路径解析） | `$HOME` |

#### 关键代码位置

- **文件：** `src/config/paths.ts:60-89`

```typescript
export function resolveStateDir(
  env: NodeJS.ProcessEnv = process.env,

  }
  // ... 默认返回 ~/.openclaw
}
```

### 2. 网关端口配置

#### 端口优先级

```
--port 命令行参数 > OPENCLAW_GATEWAY_PORT > gateway.port 配置 > 18789 (默认)
```

#### 关键代码位置

- **默认端口：** `src/config/paths.ts:214`
```typescript
export const DEFAULT_GATEWAY_PORT = 18789;
```

- **端口解析：** `src/config/paths.ts:285-301`
```typescript
export function resolveGatewayPort(
  cfg?: OpenClawConfig,
  env: NodeJS.ProcessEnv = process.env,
): number {
  const envRaw = env.OPENCLAW_GATEWAY_PORT?.trim();
  const envPort = parseGatewayPortEnvValue(envRaw);
  if (envPort !== null) {
    return envPort;
  }
  const configPort = cfg?.gateway?.port;
  if (typeof configPort === "number" && Number.isFinite(configPort)) {
    if (configPort > 0) {
      return configPort;
    }
  }
  return DEFAULT_GATEWAY_PORT;
}
```

### 3. WebSocket 端口配置

**架构特点：**
- WebSocket 和 HTTP 共用同一个端口
- 默认端口也是 `18789`
- 通过 `gateway.port` 或 `OPENCLAW_GATEWAY_PORT` 统一配置

### 4. 绑定地址配置

#### `gateway.bind` 选项

| 值 | 绑定地址 | 说明 |
|----|----------|------|
| `loopback` (默认) | `127.0.0.1` | 仅本机访问 |
| `lan` | `0.0.0.0` | 所有网络接口 |
| `tailnet` | Tailscale IP | 仅 Tailscale 网络 |
| `custom` | 自定义地址 | 需配合 `customBindHost` |

#### 关键代码位置

- **绑定解析：** `src/canvas-host/server.ts:466`
```typescript

```

## 实际修改方法

### 方法一：通过环境变量（推荐）

```bash
# 编译前设置环境变量
export OPENCLAW_STATE_DIR=/custom/path/to/openclaw
export OPENCLAW_GATEWAY_PORT=19001

# 编译
pnpm build

# 运行时使用相同的环境变量
openclaw gateway --port 19001
```

### 方法二：通过配置文件

编辑 `~/.openclaw/openclaw.json`：

```json5
{
  gateway: {
    mode: "local",
    port: 19001,
    bind: "loopback",  // 或 "lan" / "tailnet" / "custom"
    auth: {
      token: "your-token"  // 非环回绑定需要认证
    }
  }
}
```

### 方法三：命令行参数

```bash
# 直接运行时指定
openclaw gateway --port 19001

# 使用 --dev 快速开发模式（端口 19001，目录 ~/.openclaw-dev）
openclaw --dev gateway --allow-unconfigured

# 使用 --profile 自定义配置
openclaw --profile my-profile gateway --port 19002
```

## 安全注意事项

1. **默认安全绑定**：默认使用 `loopback` 绑定 (`127.0.0.1`) 是安全默认值
2. **认证要求**：如果需要跨机器访问（如 `bind: "lan"`），必须配置 `gateway.auth` 认证
3. **非环回绑定警告**：系统会对非环回绑定且无认证的配置发出安全警告

## 多实例配置

如需在同一主机运行多个网关实例，需要确保：

```bash
# 实例 A
OPENCLAW_CONFIG_PATH=~/.openclaw/a.json \
OPENCLAW_STATE_DIR=~/.openclaw-a \
openclaw gateway --port 19001

# 实例 B
OPENCLAW_CONFIG_PATH=~/.openclaw/b.json \
OPENCLAW_STATE_DIR=~/.openclaw-b \
openclaw gateway --port 19002
```

## 技术洞察

`★ Insight ─────────────────────────────────────`
1. **单一端口架构**：OpenClaw 的网关采用 WebSocket 和 HTTP 共享端口的设计，简化了防火墙配置和网络路由
2. **环境变量优先**：`OPENCLAW_GATEWAY_PORT` 环境变量的优先级高于配置文件，便于在 CI/CD 或容器环境中覆盖默认值
3. **安全性绑定**：默认使用 `loopback` 绑定 (`127.0.0.1`) 是安全默认值，如果需要跨机器访问，必须配置 `auth` 认证
