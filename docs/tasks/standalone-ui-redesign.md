# Standalone Chat UI 改版计划

> 基于 Figma 设计稿：综合助手小渥虾 (node-id: 8-48955)

## 设计概要

设计稿将 standalone 聊天页面改为 WarrenQ 风格的桌面客户端布局（1440x900），包含 6 个主要区域：

| 区域 | 尺寸 | 主色 | 说明 |
|------|------|------|------|
| 顶部导航 | 1440x40 | #081452 | Logo + 搜索 + 积分 + 头像 + 窗口控制 |
| 左侧图标栏 | 56x860 | #081452 | 6个导航图标（综合助手/定时任务/技能广场/专家Agent/文档中心/我的自选） |
| 页签栏 | 1384x32 | #394375 | 活跃标签 + 导航按钮（撤销/重做/刷新/更多/历史） |
| 导航侧栏 | 240x826 | white | 工作区名 + 新建对话 + 搜索对话 + 对话列表 |
| 欢迎区+任务卡片 | 908xauto | white | 机器人图标 + "综合智能助手"渐变文字 + 4列定时任务卡 |
| 输入框 | 908x160 | white | 模型选择器 + 技能/专家按钮 + 附件 + 发送 |

## 关键文件

| 文件 | 改动类型 |
|------|----------|
| `ui/src/styles/chat-standalone.css` | 重写布局和主题色 |
| `ui/src/ui/views/chat-standalone.ts` | 增加顶部导航/图标栏/页签栏渲染 |
| `ui/src/ui/views/chat-standalone/empty-state.ts` | 重写欢迎区域 |
| `ui/src/ui/app-render.ts` | 可能需要调整渲染入口 |

## 风险和约束

1. **仅影响 standalone 模式**：所有改动在 `.chat--standalone` 选择器内，不影响嵌入式聊天
2. **图标资源**：设计稿使用大量 SVG 图标，需要用 SVG inline 或 icon font 替代
3. **功能范围**：设计稿中部分功能（定时任务、技能广场、专家Agent）目前可能无后端支持，先做 UI 展示
4. **响应式**：设计稿为 1440px 桌面端，需考虑小屏适配
