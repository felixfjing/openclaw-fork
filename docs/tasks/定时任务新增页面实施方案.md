## 技术方案

### 路由设计

使用 hash 路由: `#cron/create`
- 定时任务列表页: `#cron` (已实现)
- 新增页面: `#cron/create` (新增)
- 点击 "新增" → `window.location.hash = '#cron/create'`
- 点击 "取消"/"保存" → `window.location.hash = '#cron'`

### 文件变更清单

#### 1. 新建 `chat-standalone/cron-create.ts`

表单组件，导出 `renderCronCreatePage` 函数：

```typescript
interface CronCreateForm {
  taskName: string;
  workspace: string;
  prompt: string;
  model: string;
  cycleType: "daily" | "tradingDay" | "weekly" | "monthly";
  weekDay: string;
  monthDay: string;
  monthWeekDay: string;
  hour: string;
  minute: string;
}

export function renderCronCreatePage(
  props: ChatProps,
  form: CronCreateForm,
  onFormChange: (field: keyof CronCreateForm, value: string) => void,
  onSave: () => void,
  onCancel: () => void,
): TemplateResult
```

#### 2. 修改 `chat-standalone/state.ts`

新增表单状态字段到 `ChatEphemeralState`：
- `cronCreateForm: CronCreateForm` — 表单数据
- 添加 `createDefaultCronForm()` 工厂函数

#### 3. 修改 `chat-standalone.ts`

扩展 hash 路由检测：
```typescript
function isCronRoute(): boolean {
  const hash = window.location.hash;
  return hash === "#cron" || hash === "#cron/create";
}

function isCronCreateRoute(): boolean {
  return window.location.hash === "#cron/create";
}
```

在 `renderChatStandalone` 中增加 `#cron/create` 分支。

#### 4. 修改 `chat-standalone/cron-page.ts`

"新增" 按钮改为 hash 导航：
```typescript
@click=${() => { window.location.hash = '#cron/create'; }}
```

#### 5. 修改 `chat-standalone.css`

新增 `.cron-create` 系列样式：
- `.cron-create` — 表单容器, 居中, 672px
- `.cron-create__section` — 分区容器
- `.cron-create__section-title` — 区块标题 (14px Semibold)
- `.cron-create__field` — 表单行 (label + input)
- `.cron-create__label` — 标签 (14px, required 红色标记)
- `.cron-create__input` — 输入框 (32px, 4px 圆角)
- `.cron-create__textarea` — 文本域 (115px)
- `.cron-create__model-bar` — 模型选择器
- `.cron-create__radio-group` — 单选按钮组
- `.cron-create__time-picker` — 时间选择器
- `.cron-create__footer` — 底部操作栏
- `.cron-create__btn-*` — 按钮变体
