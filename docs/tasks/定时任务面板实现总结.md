## Figma 设计对应

### 头部栏（32px）

- 左侧：闹钟图标（alarm，#0080ff）+ "定时任务" 标签 + 蓝色统计徽章（今天执行X次，成功X次，失败X次）
- 右侧："更多" 文字（#8e9091，12px）+ 右箭头

### 内容区

- 多列自适应卡片网格（`grid-template-columns: repeat(auto-fill, minmax(240px, 1fr))`）
- 每张卡片包含：
  - 卡片标题（任务名称，14px 加粗，带灰色底色）
  - 执行记录项：
    - 文件图标 + 任务描述 + 状态（成功/失败图标+文字）
    - 执行时间标签 + 时间值
  - 下次执行时间（如有）
  - 调度规则（如有）

### 空状态

- 无定时任务时显示虚线框 + "暂无定时任务" 提示

## 统计计算逻辑

`computeTodayStats()` 从 `CronJob[]` 中统计今日执行情况：
- 遍历所有任务，筛选 `state.lastRunAtMs` 在今天范围内的
- 按照上次运行状态统计结果：成功数和失败数

## 数据来源

- `ChatProps.cronJobs` → `CronJob[]`
- 每个 `CronJob` 包含：`name`、`schedule`、`state`（`lastStatus`、`lastRunAtMs`、`nextRunAtMs`、`lastDurationMs` 等）
- `payload` 支持 `systemEvent` 和 `agentTurn` 两种类型
